# Тріаж інбоксу запитів — Telegram-бот

Демо до тестового завдання: сервіс класифікує та структурує запити внутрішніх
команд, які приходять у вільній формі.

Бот приймає довільний запит українською і повертає розібрану картку:
категорія, відділ-замовник, пріоритет із поясненням, конкретні дії,
чи потрібне уточнення.

Доступ за словом-паролем — бот ходить у Gemini, а безкоштовний тір там
обмежений 5 запитами на хвилину.

Код і пояснення рішення: https://github.com/DanilAra7/fractaltest

## Змінні (Settings → Variables and secrets)

| Секрет | Навіщо |
|---|---|
| `GEMINI_API_KEY` | ключ до моделі |
| `TELEGRAM_BOT_TOKEN` | токен бота від @BotFather |
| `TELEGRAM_ACCESS_WORD` | слово-пароль; без нього бот не стартує |
